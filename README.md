# GitHub Test - Personal Guide

Welcome to my **personal reference guide** repository. This is a place where I document important concepts, tutorials, and code snippets that I can revisit and refer to when learning Git, Python, and other programming topics.

## Contents

- **Guides**: A collection of markdown files with learning guides.
  - `git_basics.md` - Basic Git commands and usage.
  - `python_basics.md` - Key Python concepts and examples.
  - `best_practices.md` - GitHub and Python best practices.

- **Resources**: A compilation of useful external links and tutorials.
  - `useful_links.md` - Links to essential learning resources.
  - `tutorials.md` - Tutorials that help deepen my understanding.

- **Source Code**: Python scripts for practice.
  - `hello.py` - Simple Python script that prints "Hello, World!"
  - `greet.py` - Python script that prompts for a name and greets the user.

- **Data Files**: Sample data for testing or practice.
  - `data.txt` - Simple text data file.

---

## How to Use This Repository

This repository is a living guide. Whenever I learn something new or find helpful resources, I’ll add them here.

- To get started with the code, run the Python scripts in the `src/` folder.
- Use the guides in `guides/` as references when learning new concepts or working on projects.
- Explore the resources in the `resources/` folder for additional learning materials.
